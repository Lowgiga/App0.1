## Korrektur

Die erste Fassung dieser Seite (Commit `69462c0`) hatte Statuswerte und Gates aus einer älteren Matrixfassung von `main` abgeschrieben, zum Beispiel G0–G3 als offen. Das war falsch. Seitdem wird die Tabelle erzeugt. Beim Aufbau des Parsers fiel in der Matrix außerdem `**Implementiert:**17` (UX-01) auf. Nach CommonMark schließt dieses `**` nicht, GitHub zeigte also die Sternchen. Die Stelle ist korrigiert.
